## data/sft/toy.jsonl：决策格式示例与低置信度形态谱系

toy.jsonl 是 SFT 管线的 canary 燃料（只验证代码，不产出能力），同时是后续构造正式数据时的
**格式锚点**：正式构造数据（通用分类任务文本化）的 prompt/completion 结构以本文件为参考样例。

格式约定（构造数据必须遵守）：

- prompt 三字段顺序固定：候选类别 → 类别说明 → 待判样本；
- completion 两字段固定：决策 → 置信度（0~1 数值）。

样本谱系（九条，正式构造数据按此配齐三种低置信度形态的比例）：

| 形态 | 机制 | toy 示例 | 期望输出 |
| --- | --- | --- | --- |
| 正常锚点 | 证据唯一匹配 | 苹果/香蕉；猫/狗两条 | 高置信度决策 |
| 排除机制 | 真值不在候选列表内 | 候选只有 ICML/NeurIPS，样本是 AAAI 论文 | 无法判断（拒识）——对应部署中的未知故障模式 |
| 歧义机制 | 证据不足以区分候选 | 待判样本只有"一篇论文" | 无法判断（拒识） |
| 证据冲突 | 多个类别说明都看似匹配 | 猫的"体型小夜行"与狗的"听觉灵敏会吠叫"同时命中 | 低置信度决策（0.55，低于成本矩阵作答阈值 0.625，在完整决策协议下将被拒识） |

注意（设计要点，评审可能追问）：

- 排除与歧义两种拒识机制的**输出标签同为"无法判断"**——部署语义相同（都触发人工复核）、
成本矩阵同价（-0.5）、模型视角不可分（它看不到构造时真值是否被排除）；
- 两种机制的区分落在**构造层**（正式数据里两种都要有明确占比）与**评测层**（AMR 指标天然分层：
排除机制强制作答必错、AMR=1.0；歧义机制可蒙对、AMR 更低；开发集可按机制分层报告）；
- 置信度数值在 SFT 阶段仅为格式占位（教"报数"，不教"报准"）；校准由 RLCD 与判别版温度拟合负责。
